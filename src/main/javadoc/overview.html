Jimbe — Java EBML/Matroska Library

Jimbe is a Java library for reading and writing EBML (Extensible Binary Meta Language) and Matroska/WebM container files. It provides both a low-level EBML element API and a high-level Matroska API with track management, frame-level random access, seeking, and metadata support.

Architecture

The library is organized into five packages:

Package overview
Package Description
{@link org.atriasoft.jimbe.io} I/O interfaces ({@link org.atriasoft.jimbe.io.DataSource}, {@link org.atriasoft.jimbe.io.DataWriter}) and file-based implementations. Pluggable: implement these interfaces to read/write from custom sources.
{@link org.atriasoft.jimbe.ebml} Low-level EBML reader and writer. Handles variable-length integer encoding, element ID resolution, and raw element serialization.
{@link org.atriasoft.jimbe.ebml.model} EBML element type hierarchy: {@link org.atriasoft.jimbe.ebml.model.Element}, {@link org.atriasoft.jimbe.ebml.model.MasterElement}, {@link org.atriasoft.jimbe.ebml.model.BinaryElement}, {@link org.atriasoft.jimbe.ebml.model.StringElement}, {@link org.atriasoft.jimbe.ebml.model.UnsignedIntegerElement}, etc. Also contains {@link org.atriasoft.jimbe.ebml.model.ProtoType} for element registration.
{@link org.atriasoft.jimbe.matroska} High-level Matroska/WebM API. {@link org.atriasoft.jimbe.matroska.Reader} parses files and provides frame-by-frame access with seeking. {@link org.atriasoft.jimbe.matroska.Writer} creates Matroska files with tracks, clusters, and cue points.
{@link org.atriasoft.jimbe.matroska.model} Matroska data model: {@link org.atriasoft.jimbe.matroska.model.Track}, {@link org.atriasoft.jimbe.matroska.model.Frame}, {@link org.atriasoft.jimbe.matroska.model.Cluster}, {@link org.atriasoft.jimbe.matroska.model.DocTypes}, and more.

Getting Started

Maven Dependency

{@code

    org.atria-soft
    jimbe
    1.0.0-SNAPSHOT

}

Reading a Matroska File

{@code
FileDataSource source = new FileDataSource("video.mkv");
Reader reader = new Reader(source);
reader.readFile();

// List tracks
for (Track track : reader.getTrackList()) {
    System.out.println(track);
}

// Read frames sequentially
Frame frame;
while ((frame = reader.getNextFrame()) != null) {
    System.out.printf("Track %d, timecode %d, %d bytes%n",
        frame.getTrackNo(), frame.getTimecode(), frame.getData().remaining());
}
}

Reading Frames from a Specific Track

{@code
Frame frame;
while ((frame = reader.getNextFrame(1)) != null) {
    // Process only track 1 frames
}
}

Seeking

{@code
if (reader.isSeekable()) {
    long actualTimecode = reader.seek(5000); // Seek to 5000ms
    Frame frame = reader.getNextFrame();     // First frame at or after seek point
}
}

Getting File Metadata

{@code
System.out.println("Title: " + reader.getSegmentTitle());
System.out.println("Muxing app: " + reader.getMuxingApp());
System.out.println("Writing app: " + reader.getWritingApp());
System.out.println("Timecode scale: " + reader.getTimecodeScale());
System.out.println(reader.getReport()); // Full file summary
}

Writing a Matroska File

{@code
FileDataWriter output = new FileDataWriter("output.mkv");
Writer writer = new Writer(output);

// Define a track
Track track = new Track();
track.setTrackNo(1);
track.setTrackType(TrackType.SUBTITLE);
track.setCodecID("S_TEXT/UTF8");
track.setDefaultDuration(1000);
writer.addTrack(track);

// Write frames
Frame frame = new Frame();
frame.setTrackNo(1);
frame.setTimecode(0);
frame.setData(ByteBuffer.wrap("Hello!".getBytes(StandardCharsets.UTF_8)));
writer.addFrame(frame);

writer.close();
output.close();
}

Writing with a Video Track

{@code
Track videoTrack = new Track();
videoTrack.setTrackNo(1);
videoTrack.setTrackType(TrackType.VIDEO);
videoTrack.setCodecID("V_VP8");
videoTrack.setDefaultDuration(33333333L); // ~30fps in nanoseconds

VideoTrack videoInfo = new VideoTrack();
videoInfo.setPixelWidth((short) 1920);
videoInfo.setPixelHeight((short) 1080);
videoTrack.setVideo(videoInfo);

writer.addTrack(videoTrack);
}

Low-level EBML Access

{@code
FileDataSource source = new FileDataSource("file.mkv");
org.atriasoft.jimbe.ebml.Reader reader = new org.atriasoft.jimbe.ebml.Reader(source);

Element element = reader.readNextElement();
while (element != null) {
    System.out.printf("Element: %s, size: %d%n",
        element.getElementType().getName(), element.getSize());

    if (element instanceof MasterElement master) {
        Element child = master.readNextChild(reader);
        // traverse children...
    }
    element.skipData(source);
    element = reader.readNextElement();
}
}
